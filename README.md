
# Student Management System

Student Name: Nadia Mamdouh

## Description
A C# console application that manages student data, including name, age, and GPA,
and calculates each student's grade. 
It demonstrates object-oriented programming concepts:
encapsulation, constructors, inheritance, and polymorphism.

## How to Run
1.Install the [.NET SDK]
2.Clone the repository
3.Open the project in IDE
4.Run the project
